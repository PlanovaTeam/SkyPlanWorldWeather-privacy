Política de Privacidad – SkyPlan World Weather

Última actualización: 01.11.2026

SkyPlan World Weather es una aplicación de planificación operativa diseñada para funcionar sin infraestructura de servidores propios. Los datos generados por la aplicación permanecen en el dispositivo del usuario, salvo cuando sea necesario para el funcionamiento de las funciones solicitadas.

1. Datos personales

SkyPlan World Weather no requiere crear una cuenta y no recopila directamente datos personales identificativos, como el nombre, la dirección de correo electrónico o los contactos.

Las posibles compras dentro de la aplicación se gestionan exclusivamente a través de Apple App Store y Google Play Store, conforme a sus respectivas condiciones.

2. Uso de la ubicación del dispositivo

SkyPlan World Weather puede solicitar acceso a la ubicación del dispositivo.

La ubicación se utiliza exclusivamente para proporcionar previsiones meteorológicas locales dentro de la aplicación.

Para obtener esas previsiones, las coordenadas geográficas pueden transmitirse a servicios meteorológicos externos.

La ubicación no se utiliza con fines de seguimiento, elaboración de perfiles ni publicidad.

3. Ubicación de las actividades

Las actividades planificadas pueden asociarse a una ubicación geográfica.

Las coordenadas utilizadas por la aplicación proceden de:

  • la selección mediante servicios de mapas
  • procesos de geocodificación o geocodificación inversa

Esta información se utiliza exclusivamente para determinar el contexto operativo de las actividades y procesar las condiciones ambientales.

4. Servicios externos

Para el funcionamiento de sus funciones, SkyPlan World Weather interactúa directamente con servicios externos, entre ellos:

  • servicios meteorológicos, para obtener datos de previsión
  • servicios de geocodificación y ubicación, para gestionar coordenadas

Las solicitudes a estos servicios pueden incluir coordenadas geográficas o información necesaria para identificar ubicaciones.

5. Acceso a los calendarios

SkyPlan World Weather puede solicitar autorización para acceder a los calendarios disponibles en el dispositivo y sincronizar las actividades con Google Calendar, previo consentimiento del usuario.

Si se concede la autorización, la aplicación puede crear y leer eventos para representar las actividades planificadas.

La gestión, sincronización y compartición de los calendarios se realiza exclusivamente a través de los servicios elegidos por el usuario y queda bajo su responsabilidad.

6. Almacenamiento de datos

Todos los datos de la aplicación, incluidas las actividades y los ajustes, se almacenan exclusivamente en el dispositivo del usuario.

SkyPlan World Weather no utiliza servidores propios para almacenar ni procesar dichos datos.

7. Transferencia de datos

SkyPlan World Weather no vende datos personales ni los comparte con fines publicitarios o de elaboración de perfiles.

Los datos pueden transmitirse exclusivamente en los siguientes casos:

  • solicitud de datos meteorológicos
  • uso de servicios de geocodificación
  • acceso a los calendarios del dispositivo
  • exportaciones iniciadas por el usuario

8. Servicios de terceros

SkyPlan World Weather puede interactuar:

  • directamente con servicios meteorológicos y de ubicación
  • indirectamente con servicios de calendario y sistemas de pago (Apple / Google)

Estos servicios se rigen por sus propias condiciones y políticas de privacidad.

9. Control del usuario

El usuario puede, en cualquier momento:

  • desactivar el acceso a la ubicación desde los ajustes del dispositivo
  • gestionar los permisos de calendario desde el sistema operativo
  • eliminar los datos de la aplicación desinstalándola
