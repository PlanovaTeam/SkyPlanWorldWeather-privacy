Política de Privacidade – SkyPlan World Weather

Última atualização: 01.11.2026

SkyPlan World Weather é um aplicativo de planejamento operacional desenvolvido para funcionar sem infraestrutura própria de servidores. Os dados gerados pelo aplicativo permanecem no dispositivo do usuário, exceto quando necessário para o funcionamento dos recursos solicitados.

1. Dados pessoais

SkyPlan World Weather não exige a criação de uma conta e não coleta diretamente dados pessoais que permitam identificar o usuário, como nome, endereço de e-mail ou contatos.

As eventuais compras dentro do aplicativo são processadas exclusivamente pela Apple App Store e pela Google Play Store, de acordo com seus respectivos termos.

2. Uso da localização do dispositivo

SkyPlan World Weather pode solicitar acesso à localização do dispositivo.

A localização é utilizada exclusivamente para fornecer previsões meteorológicas locais dentro do aplicativo.

Para obter essas previsões, as coordenadas geográficas podem ser transmitidas a serviços meteorológicos externos.

A localização não é utilizada para rastreamento, criação de perfis ou publicidade.

3. Localização das atividades

As atividades planejadas podem estar associadas a uma localização geográfica.

As coordenadas utilizadas pelo aplicativo são obtidas por meio de:

  • seleção em serviços de mapas
  • processos de geocodificação ou geocodificação reversa

Essas informações são utilizadas exclusivamente para determinar o contexto operacional das atividades e analisar as condições ambientais.

4. Serviços externos

Para o funcionamento de seus recursos, SkyPlan World Weather interage diretamente com serviços externos, incluindo:

  • serviços meteorológicos, para obter dados de previsão
  • serviços de geocodificação e localização, para gerenciar coordenadas

As solicitações a esses serviços podem incluir coordenadas geográficas ou informações necessárias para identificar localidades.

5. Acesso aos calendários

SkyPlan World Weather pode solicitar autorização para acessar os calendários disponíveis no dispositivo e sincronizar as atividades com o Google Agenda, mediante consentimento do usuário.

Se a autorização for concedida, o aplicativo poderá criar e ler eventos para representar as atividades planejadas.

O gerenciamento, a sincronização e o compartilhamento dos calendários ocorrem exclusivamente por meio dos serviços escolhidos pelo usuário e permanecem sob sua responsabilidade.

6. Armazenamento de dados

Todos os dados do aplicativo, incluindo atividades e configurações, são armazenados exclusivamente no dispositivo do usuário.

SkyPlan World Weather não utiliza servidores próprios para armazenar ou processar esses dados.

7. Transferência de dados

SkyPlan World Weather não vende dados pessoais nem os compartilha para fins de publicidade ou criação de perfis.

Os dados podem ser transmitidos exclusivamente nos seguintes casos:

  • solicitação de dados meteorológicos
  • uso de serviços de geocodificação
  • acesso aos calendários do dispositivo
  • exportações iniciadas pelo usuário

8. Serviços de terceiros

SkyPlan World Weather pode interagir:

  • diretamente com serviços meteorológicos e de localização
  • indiretamente com serviços de calendário e sistemas de pagamento (Apple / Google)

Esses serviços operam de acordo com seus próprios termos e políticas de privacidade.

9. Controle do usuário

O usuário pode, a qualquer momento:

  • desativar o acesso à localização nas configurações do dispositivo
  • gerenciar as permissões dos calendários pelo sistema operacional
  • excluir os dados do aplicativo ao desinstalá-lo
